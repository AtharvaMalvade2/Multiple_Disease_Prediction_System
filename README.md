# 🏥 Multiple Disease Prediction System

A Machine Learning based application that predicts the likelihood of multiple diseases such as **Diabetes**, **Heart Disease**, and **Parkinson’s Disease** using trained ML models. This system helps in early detection and assists users in making informed health decisions.

---

## 📂 Project Structure

- `Colab Files/` : Jupyter notebooks used for training and testing ML models  
- `Datasets/` : Dataset files used for training the prediction models  
- `diabetes_model.sav` : Trained Machine Learning model for Diabetes prediction  
- `heart_disease_model.sav` : Trained Machine Learning model for Heart Disease prediction  
- `parkinsons_model.sav` : Trained Machine Learning model for Parkinson’s prediction  
- `mdp.py` : Main Python application file for running predictions  
- `requirements.txt` : Required Python dependencies

## 🛠️ Setup & Installation

### Step 1: Clone the Repository

```bash
git clone https://github.com/AtharvaMalvade2/Multiple_Disease_Prediction_System.git
cd Multiple_Disease_Prediction_System
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Run the Application

Run using Python:

```bash
python mdp.py
```

Or run using Streamlit:

```bash
streamlit run mdp.py
```
